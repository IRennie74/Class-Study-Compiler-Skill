Methods for this unit: each practice problem lists the ones it uses

  1. Flags after cmp. For cmp b,a, compute a − b twice. As signed numbers: ZF (zero), SF (negative), OF (result outside the type's range: pos − neg = neg, or neg − pos = pos). As unsigned numbers: CF = 1 if a < b (a borrow).
  2. Reading cmp/test + jump/set. cmp b,a ; jX L = "if (a X b) goto L". g/l = signed, a/b = unsigned, e/ne = either. testq r,r compares r with 0 (je: r == 0, js: r < 0, jg: r > 0, jle: r ≤ 0). testq $1,r ; jne = r is odd.
  3. Type and comparison from cmp + set. The suffix and register give the size (b char, w short, l int, q long/pointer). The set letter gives signedness. Read the operands backwards: cmp %rsi,%rdi ; setl = a < b.
  4. C comparison → assembly. cmp b,a (sized to the type) → setX %al (signed g/l…, unsigned a/b…) → movzbl %al,%eax → ret.
  5. if / else-if → C. (1) Annotate the arithmetic. (2) Label the blocks. (3) Write both edges of every conditional jump: the jump edge has its condition, the fall-through edge has the negation. (4) The fall-through condition is the C if test. (5) A value computed before the first test is the initial val. Each ret ends a path. (6) Test one input per path.
  6. Reading cmov. The value already in the destination is the default. cmovX s,d = "if X, use s instead". So the C is X ? s-value : default. Both values are always computed first.
  7. When cmov cannot be used. cmov evaluates both sides, so the compiler must branch instead if a side could fault (null dereference p ? *p : 0), has side effects (x*=7), or is expensive.
  8. && / || short-circuit. Each operand of && becomes its own test and jump to "done" (the second test is skipped if the first fails). Goto form: if (!A) goto done; if (!B) goto done; body; done:.
  9. C → goto form → branch assembly. if (T) X; else Y; → if (!T) goto Else; X; goto Done; Else: Y; Done:. In assembly: cmp, then jump on the negated condition to the else label. Each path ends in ret or jumps to Done.
  10. Divide by 2k (bias idiom). leaq (2k−1)(%rdi) ; testq ; cmovns %rdi ; sarq $k = x / 2k. The bias makes negative numbers round toward 0, as C requires. Name the operator / and explain each line.

Map: x → rdi, y → rsi, z → rdx
test:
  leaq (%rdi,%rsi),%rax      rax = x+y
  addq %rdx,%rax             rax = x+y+z                  ← val = x+y+z (initial)
  cmpq $-3,%rdi              compare x : −3
  jge .L2                    jump if x ≥ −3     │ fall-through: x < −3   ⇒ if (x < -3)
  cmpq %rdx,%rsi             compare y : z
  jge .L3                    jump if y ≥ z      │ fall-through: y < z    ⇒ if (y < z)
  movq %rdi,%rax ; imulq %rsi,%rax   val = x*y ; ret
.L3: movq %rsi,%rax ; imulq %rdx,%rax  val = y*z ; ret        ⇐ else (y ≥ z)
.L2: cmpq $2,%rdi ; jle .L4  jump if x ≤ 2      │ fall-through: x > 2   ⇒ else if (x > 2)
     movq %rdi,%rax ; imulq %rdx,%rax  val = x*z
.L4: ret                                                      ⇐ return val

C:  long val = x+y+z;
    if (x < -3) { if (y < z) val = x*y; else val = y*z; }
    else if (x > 2) val = x*z;
    return val;
Check: x=−5,y=1,z=2 → asm falls through both tests → val = x·y = −5; the C also gives −5 ✓

    }

3.9 
rax = 2x                              ⇒ val = 2*x  (the result if no branch changes it)
cmpq $3,%rsi ; jle .L2   jump y ≤ 3 │ fall y > 3     ⇒ if (y > 3)
  rax = x | y   (default inside the block)
  rdx = y + x
  testq %rdi,%rdi ; cmovs → if x < 0, rax = x + y
  ⇒ if (x < 0) val = x + y; else val = x | y;
.L2: rdx = y − x ; testq %rsi,%rsi ; cmove → if y == 0, rax = y − x
  ⇒ else if (y == 0) val = y - x;
C: long val = 2*x;
   if (y > 3) { if (x < 0) val = x + y; else val = x | y; }
   else if (y == 0) val = y - x;
   return val;
Trap: inside the y > 3 block, the inner "then" is the cmov condition (x < 0 → x + y). The value computed first (x | y) is the "else".

long absmin_goto(long a, long b) {        absmin:
  long r;                                    cmpq  %rsi, %rdi    # a : b
  if (a > b) goto Else;    /* !test */      jg    .L2           # a > b → Else
  r = b - a;                                 movq  %rsi, %rax
  goto Done;                                 subq  %rdi, %rax    # b − a
Else:                                        ret
  r = a * b;                               .L2:
Done:                                        movq  %rdi, %rax
  return r;                                  imulq %rsi, %rax    # a·b
}                                            ret
