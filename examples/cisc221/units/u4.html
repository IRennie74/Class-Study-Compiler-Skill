Solving method — loops

  1. Find the loop: circle every jump to an earlier label (the back-edge). The code between that label and the back-edge is the loop.
  2. Classify the translation:
    You seeIt is
    no jump before the loop label; the test is only at the bottomdo-while
    jmp .Ltest right before the body (the test is at the bottom)while, jump-to-middle (-Og)
    a test before the loop that jumps past it, then the same test at the bottomwhile, guarded-do (-O1)
  3. Label the parts: Init = the movs before the loop. Test = the cmp/test + back-edge jump (the C condition is the jump's condition, because the back-edge is taken when the loop continues). Update = the add/sub of the counter just before the test. Body = the rest.
  4. Write it as a while. Convert to a for if there is a clear Init/Test/Update on one variable.
  5. Trace a small input in an iteration table to check your answer and to answer "what does it compute?".

Solving method — switch

  1. Offset k from subq $k / addq $−k / leaq −k(%rdi). Without one, k = 0. Table index i ↔ case i + k.
  2. Max case = (the constant in cmpq $n) + k. ja → the default label.
  3. Write a mapping table: index → case value → label.
  4. Entries that equal the default label are missing cases. Labels that appear twice are shared cases.
  5. Translate each label's block. A block with no jmp/ret at its end falls through into the next label.

4.1 
(A) jump-to-middle: an unconditional jmp to the test before the body
(B) guarded-do: a test jumps past the loop, and the same test repeats at the bottom
(C) do-while: the body runs first, and the test is only at the bottom

long p(long x) { long result = 0; do { result += x; x -= 3; } while (x > 0); return result; }

4.4 
Guarded-do (the test n > 0 before the loop, then cmpq/jg at the bottom).
.L3: rax = rax + 2·rdx + 1  → s += 2*i + 1 ;  rdx++ → i++ ;  cmpq %rdx,%rdi ; jg → n > i, i.e. i < n
long r(long n) { long s = 0; for (long i = 0; i < n; i++) s += 2*i + 1; return s; }
r(4) = 1 + 3 + 5 + 7 = 16.  In general it sums the first n odd numbers = n².
Trap: cmpq %rdx,%rdi computes rdi − rdx = n − i, so jg means n > i.

4.8 
long tz(unsigned long x) {
  long c = 0;
  if (x == 0) return 0;          // je .L4 (otherwise the loop would never end)
  while ((x & 1) == 0) {         // testq $1 ; je .L3  → continue while bit 0 is 0
    x >>= 1;  c++;
  }
  return c;
}
It counts the trailing zero bits.  tz(8) = 3 (1000₂), tz(12) = 2 (1100₂)
Note: testq $1,%rdi ; je jumps when x & 1 == 0, which is the condition for continuing the loop.
