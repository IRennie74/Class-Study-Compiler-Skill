Solving method — operand and memory questions

  1. Classify the operand before you compute anything. If it starts with $, it is an immediate: the answer is that number and you read no memory. A bare register (%rax) means its contents. Anything else (parentheses, or a bare number like 0x104) is a memory operand.
  2. For memory, compute the address with Addr = D + Rb + S·Ri. Convert everything to one base first. Displacements written without 0x are decimal.
  3. Look the address up in the memory table. The value stored there is the answer.
  4. For suffix questions, read the size from the register that is not inside parentheses (8-bit names like %al, %bl, %sil → b; 16-bit like %ax, %si → w; %eXX or %rNd → l; %rXX → q).
  5. For "what's wrong" questions, check this list in order: memory-to-memory; immediate as destination; suffix doesn't match the register; the register doesn't exist; a 32-bit register used as an address; %rsp used as the index; scale not in {1,2,4,8}.
  6. For cast moves (*dp = (dest_t)*sp): if the destination is wider, sign- or zero-extend according to the source type. If it is narrower, load at the source size and store the low part. If the sizes are equal, use a plain mov.

How to show your work (what to actually write on the quiz)

For each operand, write one line: kind → address computation → lookup → value. For a sequence of moves, keep a state table with one row per instruction. A grader can award part marks only when the computation is visible.

1.6 
short → long            movswq (%rdi),%rax   ; movq %rax,(%rsi)   signed source → sign-extend
unsigned short → long   movzwq (%rdi),%rax   ; movq %rax,(%rsi)   unsigned source → zero-extend
long → int              movq   (%rdi),%rax   ; movl %eax,(%rsi)   narrower → store low 4 bytes
char → unsigned short   movsbw (%rdi),%ax    ; movw %ax,(%rsi)    the SOURCE (char) is signed
unsigned → long         movl   (%rdi),%eax   ; movq %rax,(%rsi)   movl zeroes the upper 32 bits,
                                                                  so it IS the zero-extension (no movzlq)
int → short             movl   (%rdi),%eax   ; movw %ax,(%rsi)    narrower

1 movq (%rsi),%rax     rax = *yp          → y
2 movq (%rdx),%rcx     rcx = *zp          → z

     long x = *xp, y = *yp, z = *zp;
     *zp = y;  *xp = z;  *yp = x;
   }
