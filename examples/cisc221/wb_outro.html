R2Uses U3 M2 · U3 M6 
rax = x ; negq → rax = −x, and sets the flags from −x:
    SF = 1 when −x < 0 (i.e. x > 0); OF = 0 (except x = LONG_MIN)
cmovl (SF^OF): if −x < 0, i.e. x > 0, rax = x
Result: x > 0 ? x : −x  =  |x|  (absolute value; LONG_MIN stays LONG_MIN)
R3Uses U4 M1 · U4 M2 · U6 M9 
Guarded-do: if n ≤ 0 skip; end = a + n (rcx = a + 8n); loop until the pointer reaches end.
long cnt(long *a, long n, long t) {
  long c = 0;
  for (long *p = a; p != a + n; p++)    // (or: for (i = 0; i < n; i++) if (a[i] == t) c++;)
    if (*p == t) c++;
  return c;
}
It counts how many elements equal t.
Note: cmpq %rdx,(%rdi) compares *p : t; jne skips the increment.
R4Uses U5 M7 · U7 M4 
long sumlist(struct node *n) {
  if (n == 0) return 0;
  return n->v + sumlist(n->next);
}
%rbx holds n->v (offset 0). It is needed AFTER the recursive call, so it must be
in a callee-saved register (the call promises to preserve %rbx).
next is at offset 8, and it becomes the argument.
