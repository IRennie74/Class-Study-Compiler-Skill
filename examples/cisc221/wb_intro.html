CISC 221 — Unit-by-Unit Problem Workbook

Machine-Level Programming (x86-64), L09–L15. 70+ quiz-style problems organised by unit, each with the solving method, the exact "show your work" format to use, and fully worked solutions.
How to use this workbook. The test is all problems, so this book is too. For each unit:
  1. Read the key facts box (half a page). If something is unclear, look it up in the Concepts Notes (PDF 5).
  2. Study the solving method and the show-your-work model answer. This is the format to copy onto the quiz.
  3. Do the practice set on paper, in the boxes, without looking at the solutions. Problems are tagged easy medium harder.
  4. Turn the page and mark your work against the worked solutions. Compare your steps, not just your final answer.
  5. Then do the instructor's practice-deck problems listed in the purple box (solutions are in the Master Reference, section D).
A mixed, quiz-style set covering all units is at the end. After that, sit the full Mock Test (PDF 1).

The universal rules for showing your work

Whatever the question, the grader wants to see your reasoning chain. These seven habits get you full marks, and part marks when an arithmetic slip happens:

#HabitWhat it looks like on paper
1Write the register map firstx → %rdi, y → %rsi, z → %rdx (from the prototype)
2Annotate every instructionNext to each line: rax = x + 2y (the destination's new value, in the original variables)
3Show address arithmeticAddr = 0x10 + 0x100 + 4·2 = 0x118 → M[0x118] = 0x11
4Label control flowOn each conditional jump, write both edges: "jump if x ≥ y | fall-through x < y ⇒ if (x < y)"
5Name the loop partsINIT / BODY / UPDATE / TEST, and circle the back-edge; say which translation (do-while, jump-to-middle, guarded-do)
6Use a table for traces and layoutsA state table for move/stack traces; a layout table (field, size, align, offset, pad) for structs; index→case→label for switches
7Check with numbers, then box the answerPick small inputs, run your C and the annotated assembly, and confirm they match. Write the final C/value clearly, separate from the scratch work.
Five errors that cost the most marks. (1) Reading subq a,b as a − b (it is b − a). (2) Writing the jump's condition as the C if-test (it is usually the negation). (3) Mixing decimal and hex displacements (260 = 0x104). (4) Forgetting that leaq never reads memory. (5) Signed vs unsigned: g/l vs a/b, sar vs shr, movs vs movz.
