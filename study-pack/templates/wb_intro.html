How to use this workbook. Every unit teaches each problem type the same way, in the order you learn best:
  1. How it's asked: an example question, exactly as it appears on the test.
  2. The answer, written exactly like this: the complete answer to that example, laid out the way you should write it.
  3. How it works: the full explanation of the concept: what is going on, why, and the traps.
  4. Every time, do this: a short checklist to follow on the test.
After all of a unit's problem types (M1, M2, …) comes the practice set. Each problem is tagged Uses M2 · M5 to show which problem types it is. If you're stuck, re-read those cards, not the solutions. Do the problems on paper, then mark your steps against the worked solutions on the next page. Tags easy medium harder.
No problem uses anything its unit hasn't taught first (the build checks this). Finish with the mixed review set, then sit the Mock Test (PDF 1).
