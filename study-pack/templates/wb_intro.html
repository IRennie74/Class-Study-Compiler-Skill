How to use this workbook. It assumes you know nothing yet. Start with Unit 0, which teaches the basics everything else depends on: bits and hex, negative numbers, registers and memory, how to read a line of assembly, pointers, and how to read a problem page.

Every unit opens with a Words and symbols box: read it first, so no term is new when you meet it. Then each problem type is taught the same way:

  1. How it's asked: an example question, exactly as it appears on the test.
  2. What you're looking at: every part and symbol of that question explained, so it never looks like gibberish.
  3. The answer, written exactly like this: the complete answer, laid out the way you should write it.
  4. How it works: the full explanation of the concept: what is going on, why, and the traps.
  5. Every time, do this: a short checklist to follow on the test.
After the cards comes the practice set. Each problem is tagged Uses M2 · M5 to show which cards teach it; if you're stuck, re-read those cards. Mark your steps against the worked solutions on the next page. Tags easy medium harder. Finish with the mixed review set, then sit the Mock Test (PDF 1).
