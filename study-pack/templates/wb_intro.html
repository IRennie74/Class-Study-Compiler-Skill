How to use this workbook. Every unit runs in the same order: learn it, then practise exactly what you just learned.
  1. "By the end of this unit": the skills (M1, M2, …) you are about to learn.
  2. Learn it: the explanations and worked examples. Read them first.
  3. Solve it: the numbered methods (one per problem type) and a model answer showing exactly how to write your work.
  4. Practice set: each problem is tagged Uses M2 · M5. Stuck? Re-read those methods, not the solutions. Tags easy medium harder.
  5. Solutions (next page): compare your steps, not just the final answer.
  6. Then do the instructor's own practice problems listed in the purple box.
No problem uses anything its unit hasn't taught first. Finish with the mixed review set, then sit the Mock Test (PDF 1).
